## 文件约定

- `000-任务模板.md`：新任务的复制模板；
- `NNN-任务名称.md`：正式实现任务；
- 一个任务只包含一个可独立验收的目标；
- 修正范围较大时新建后续任务，不直接覆盖原始验收记录；
- Claude 只在任务文档指定位置追加执行报告，不改写目标和验收标准；
- Codex 负责状态更新、审查结论和最终 Git 交付。

## 持久化规则

1. Codex 将 `ready_for_claude` 的任务文档提交并推送后，再交给用户；
2. Claude 的源码改动保持未提交，等待 Codex 审查；
3. Claude 在任务文档末尾填写执行报告并将状态改为 `ready_for_codex_review`；
4. Codex 审查、修复和验证后填写审查记录，将状态改为 `completed`；
5. `completed` 文档与最终代码进入同一个提交，远端是否已交付由 Git 分支状态判断；
6. `git stash` 只存在于本机，不能作为跨电脑交接记录。

## 新建任务

复制 [任务模板](./000-任务模板.md)，替换所有尖括号占位符，并检查：

- 源码基线 commit 是否准确；
- 允许修改范围是否足够且没有过宽；
- 禁止事项是否覆盖真实数据、密钥和无关模块；
- 测试是否可离线、可重复；
- 验收标准是否能够由 Codex 独立验证。
