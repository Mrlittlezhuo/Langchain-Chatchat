## 背景

任务 007 已搭建记忆表、摘要、API、WebUI 和聊天接入，方向可保留。但 Codex 审查发现，
当前实现仍主要是“用户明确说请记住后保存一条笔记”，尚未满足任务定义的真正长期记忆：

1. 普通表达“我研究无线通信，偏好简洁中文”不会自动形成记忆；
2. “偏好简洁”改成“偏好详细”会留下冲突记录，现有测试只验证了完全相同文本去重；
3. 关键词无交集时难以召回相关记忆，跨会话验收场景不稳定；
4. 新增 API 测试在当前环境进入 `TestClient` 时卡死，Claude 报告的完整测试结果无法复现；
5. 记忆来源目前只有字符串标签，不能定位到来源会话/消息。

## 目标

在保留任务 007 架构的基础上完成以下闭环：

1. **自动提取稳定信息**
   - 自动记忆开启时，能从常见自然表达中提取姓名/身份、研究或工作方向、偏好、长期目标等稳定信息；
   - 一句话包含多个独立事实时可以形成多条结构化记忆；
   - 自动记忆关闭时停止隐式提取，但用户明确“请记住/忘记”仍应生效；
   - 规则或提取失败不能影响正常聊天，不调用真实外部模型完成离线测试。

2. **真正处理冲突与更新**
   - 为记忆建立可维护的主题/键或等价机制；
   - “我偏好简洁中文”之后再说“以后请详细回答”，应更新或停用旧偏好，只保留新值参与召回；
   - 完全重复内容继续去重，不相关的同类型记忆不能被误删。

3. **跨表达召回**
   - 用户询问“你还记得我的研究方向吗”时，应能召回“无线通信”，不能要求问题复述记忆原文；
   - 继续限制召回数量和总长度，无关记忆不能大量注入；
   - 普通聊天与 RAG 使用相同结果，当前用户本轮表达优先。

4. **来源与生命周期**
   - 自动或显式聊天记忆保留可定位的来源会话/消息信息，管理页能显示基本来源；
   - 删除会话时清理对应会话摘要，不误删已经形成的长期记忆；
   - 保持用户隔离和公共知识库边界不变。

5. **修复测试可信度**
   - 修正会卡死的记忆 API 测试夹具/写法，使整份测试能正常结束；
   - 不通过跳过、删除 API 测试或伪造结果规避问题；
   - 删除或排除任务测试误生成的 `libs/chatchat-server/data/knowledge_base/info.db`，不得提交运行数据库。

## 验收重点

- 用户无需说“请记住”，表达“我研究无线通信，偏好简洁中文”后，新会话能分别召回研究方向和回答偏好；
- 再表达“以后详细回答”后，旧的“简洁”偏好不再注入；
- 关闭自动记忆后，普通陈述不入库，但“请记住我的项目是 X”仍可手动触发；
- “忘记我的回答偏好”后相关偏好停止召回；
- A/B 用户隔离、摘要增量、普通聊天/RAG 注入和记忆管理页面保持可用；
- 迁移幂等并保留旧数据；任务 007 记忆测试、认证/会话隔离/迁移回归均能运行结束并通过。
