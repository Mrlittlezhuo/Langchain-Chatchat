## 1. 全局坐标系 (GCS)

全局坐标系（Global Coordinate System）是所有物理位置的统一参考系。

```
        +z (天顶)
         |
         |
         +------ +y (正北/正前)
        /
       /
     +x (正东/正右)
```

**约定**：
- **原点**：任意选择（通常选反射点位置）
- **+z 轴**：垂直向上（天顶方向）  
- **xy 平面**：水平面
- **坐标表示**：列向量 $\mathbf{p} = [x, y, z]^T$

**仿真场景中的位置**（示例）：
```
p_bs  = [0; -10; 10]   ← BS 在原点正南方 10m, 高度 10m
p_ref = [0;   0;  0]   ← 反射点在原点
p_ue  = [6;   6;  9]   ← UAV 在东北方, 高度 9m
```

## 2. 局部坐标系 (LCS)

局部坐标系（Local Coordinate System）是每个 UAV 载阵列的自身参考系。阵列安装在 UAV 机体上，LCS 轴与 GCS 轴之间存在姿态角（roll, pitch, yaw）。

### 2.1 LCS 轴定义（阵列坐标系）

```
        +z_LCS (阵列法向, boresight)
         |
         |  阵列平面在 xy_LCS 平面内
         +------ +y_LCS
        /
       /
     +x_LCS
```

- **+z_LCS**：阵列法向（boresight），垂直于阵列平面
- **+x_LCS, +y_LCS**：阵列平面内的正交方向（对应 UPA 的行列方向）
- 阵元位于 $z=0$ 平面，按 $(n_x d_x, n_y d_y, 0)$ 排列

### 2.2 LCS → GCS 旋转

UAV 姿态由三个欧拉角描述（Z-Y-X 旋转顺序）：

| 姿态角 | 符号 | 绕轴 | 含义 |
|--------|------|------|------|
| Roll  | $\alpha$ | x | 滚转角 |
| Pitch | $\beta$  | y | 俯仰角 |
| Yaw   | $\gamma$ | z | 偏航角 |

旋转矩阵 $\mathbf{R}_{bg} = \mathbf{R}_z(\gamma) \mathbf{R}_y(\beta) \mathbf{R}_x(\alpha)$，将 LCS 向量转为 GCS 向量：

$$\mathbf{u}_{\text{GCS}} = \mathbf{R}_{bg} \cdot \mathbf{u}_{\text{LCS}}$$

### 2.3 当前仿真简化

当前仿真中，**所有 UAV 阵列的 LCS 与 GCS 对齐**（$\alpha=\beta=\gamma=0$, $\mathbf{R}_{bg}=\mathbf{I}$）。因此 LCS 下的 AoA 估计值即是 GCS 下的方向向量。

> :warning: 后续多 UAV 协同定位时需恢复姿态角，否则各 UAV 的 AoA 无法统一到同一 GCS 框架。

## 3. 球面角度定义

### 3.1 标准球坐标（阵列信号处理约定）

球面坐标系定义方向单位向量 $\mathbf{u}(\varphi, \theta)$：

$$\boxed{\mathbf{u}(\varphi, \theta) = \begin{bmatrix} \sin\theta \cos\varphi \\ \sin\theta \sin\varphi \\ \cos\theta \end{bmatrix}}$$

| 符号 | 名称 | 定义 | 范围 |
|------|------|------|------|
| $\varphi$ | **方位角** (azimuth) | 从 $+x$ 轴在 $xy$ 平面内逆时针测量 | $[-\pi, \pi]$ |
| $\theta$ | **极角** (polar angle) | 与 $+z$ 轴的夹角，与俯仰角关系: $\text{俯仰角}=90°-\theta$ | $[0, \pi]$ |

### 3.2 几何意义

```
θ = 0°    →  u = [0, 0, 1]^T    (正上方, 天顶)
θ = 90°   →  u = [cosφ, sinφ, 0]^T (水平面内)
θ = 180°  →  u = [0, 0, -1]^T   (正下方, 天底)

φ = 0°    →  u = [sinθ, 0, cosθ]^T   (+x 方向)
φ = 90°   →  u = [0, sinθ, cosθ]^T   (+y 方向)
φ = ±180° →  u = [-sinθ, 0, cosθ]^T  (-x 方向, 与 φ=180° 等价)
```

### 3.3 俯仰角与极角的关系

到达角由两部分组成：**方位角** $\varphi$ 和 **俯仰角**。导向矢量公式中使用的 $\theta$ 是极角（从 $+z$ 轴测量），它和工程俯仰角的关系为：

$$\boxed{\text{俯仰角} = 90° - \theta}$$

| | 极角 $\theta$ (公式中使用) | 俯仰角 (物理含义) |
|------|------|------|
| **参考** | 从 $+z$ 轴测量 | 从水平面 ($xy$) 测量，向上为正 |
| **范围** | $[0, \pi]$ | $[-90°, 90°]$ |
| 正上方 | $\theta = 0°$ | 俯仰角 $= 90°$ |
| 水平 | $\theta = 90°$ | 俯仰角 $= 0°$ |
| 正下方 | $\theta = 180°$ | 俯仰角 $= -90°$ |

> **为什么导向矢量用极角 $\theta$ 而不用俯仰角？**
> 
> 方向向量的分量是 $\sin\theta\cos\varphi$, $\sin\theta\sin\varphi$, $\cos\theta$，直接使用极角 $\theta$ 可以避免三角转换（$\sin(90°-\alpha) = \cos\alpha$ 等），且 $\sin\theta \ge 0$ 在 $[0,\pi]$ 上始终非负。但物理上，$\theta$ 和俯仰角描述的是同一个几何量——信号来向相对于水平面的高低。

**仿真示例**：
- UAV 在反射面上方接收信号 → 俯仰角 $> 0°$（来自下方） → 极角 $\theta < 90°$
- BS 向地面反射点发射波束 → 俯仰角 $< 0°$（向下发射） → 极角 $\theta > 90°$

### 3.4 几何意义

$\theta > 90^\circ$ 表示方向向量有向下的分量（$-z$ 方向）。例如：
- BS 在反射面上方，向反射点发射波束 → $\theta_{\text{tx}} > 90^\circ$（波束向下）
- UAV 在反射面上方，接收来自反射点的信号 → $\theta_{\text{rx}} < 90^\circ$（来自下方）

## 4. 方向向量与角度互转

### 4.1 角度 → 方向向量

```matlab
function u = angles_to_vec(phi, theta)
    u = [sin(theta) * cos(phi);
         sin(theta) * sin(phi);
         cos(theta)];
end
```

### 4.2 方向向量 → 角度

```matlab
function [phi, theta] = vec_to_angles(u)
    u = u / norm(u);          % 确保单位向量
    phi   = atan2(u(2), u(1)); % 方位角: [-π, π]
    theta = acos(u(3));        % 俯仰角: [0, π]
end
```

> **关键**：$\varphi = \operatorname{atan2}(u_y, u_x)$，**不是** $\operatorname{atan2}(u_x, u_y)$。

## 5. 导向矢量

### 5.1 通用定义

对于 $N_x \times N_y$ 的 UPA（半波长间距，阵元在 $z=0$ 平面），方向 $(\varphi, \theta)$、波长 $\lambda$ 的导向矢量为：

$$\boxed{\mathbf{a}(\varphi, \theta, \lambda) = \exp\!\left[-j\frac{2\pi}{\lambda}\Big(m_x d_x \sin\theta \cos\varphi + m_y d_y \sin\theta \sin\varphi\Big)\right]}$$

其中 $m_x = 0,1,\dots,N_x-1$, $m_y = 0,1,\dots,N_y-1$，$\mathbf{a} \in \mathbb{C}^{N_x N_y \times 1}$。

**符号约定**：指数中的**负号**是阵列信号处理的标准约定——远场平面波到达阵元 $m$ 时，相对于参考阵元（原点）的相位延迟为负（波前先到更近的阵元）。

### 5.2 代码实现

```matlab
mx = repmat((0:N_rx-1).', N_ry, 1);   % x 方向阵元索引
my = repelem((0:N_ry-1).', N_rx, 1);   % y 方向阵元索引

lam = c / f;                            % 波长
mu = (2*pi/lam) * (mx * dx * sin(theta) * cos(phi) ...
                 + my * dy * sin(theta) * sin(phi));
a = exp(-1j * mu);                      % 导向矢量 (Nr × 1)
```

### 5.3 导向矢量的 Kronecker 结构

UPA 的导向矢量可分解为两个 ULA 导向矢量的 Kronecker 积：

$$\mathbf{a}(\varphi, \theta, \lambda) = \mathbf{a}_y \otimes \mathbf{a}_x$$

其中：
$$\begin{aligned}
\mathbf{a}_x[n_x] &= \exp\!\left(-j\frac{2\pi}{\lambda} d_x n_x \sin\theta \cos\varphi\right) \\
\mathbf{a}_y[n_y] &= \exp\!\left(-j\frac{2\pi}{\lambda} d_y n_y \sin\theta \sin\varphi\right)
\end{aligned}$$

## 6. 发射角 (AoD) 与到达角 (AoA)

### 6.1 定义

| 术语 | 符号 | 含义 | 视角 |
|------|------|------|------|
| **AoD** (Angle of Departure) | $(\varphi_t, \theta_t)$ | BS 发射波束的方向 | 从 BS 向外看 |
| **AoA** (Angle of Arrival) | $(\varphi_r, \theta_r)$ | UAV 接收信号的来波方向 | 从 UAV 向外看（指向源） |

### 6.2 AoA 的物理含义（重要！）

AoA $(\varphi_r, \theta_r)$ 对应的方向向量 $\mathbf{u}_{\text{aoa}} = [\sin\theta_r \cos\varphi_r, \sin\theta_r \sin\varphi_r, \cos\theta_r]^T$ 指向**波传播方向**，即从**信号源指向接收阵列**。

在反射场景中：
- 信号源 = 反射点
- 接收阵列 = UAV
- $\mathbf{u}_{\text{aoa}}$ 指向 **反射点 → UAV** 方向

$$\boxed{\mathbf{v}_{\text{out}} = \mathbf{u}_{\text{aoa}} = \begin{bmatrix} \sin\theta_r \cos\varphi_r \\ \sin\theta_r \sin\varphi_r \\ \cos\theta_r \end{bmatrix}}$$

**不需要取反！** 这是之前代码中的 bug——错误地对 $\mathbf{u}_{\text{aoa}}$ 取了负号。

### 6.3 AoD 与 AoA 的关系

在反射场景中，AoD 和 AoA 通过反射面法向量 $\mathbf{n}$ 关联：

$$\mathbf{r}_{\text{spec}} = \mathbf{v}_{\text{in}} - 2(\mathbf{v}_{\text{in}}^T \mathbf{n}) \mathbf{n}$$

其中 $\mathbf{v}_{\text{in}} = \mathbf{u}_{\text{aod}}$（BS 发射方向），$\mathbf{r}_{\text{spec}}$ 为镜面反射方向。

AoA 方向 $\mathbf{v}_{\text{out},k}$（反射点 → UAV $k$）与 $\mathbf{r}_{\text{spec}}$ 之间的夹角 $\beta$ 决定 Phong 散射强度：

$$\cos\beta_{n,k} = \mathbf{r}_{\text{spec},n}^T \mathbf{v}_{\text{out},k}$$

## 7. 仿真中的角度使用

### 7.1 发射端（BS）

```matlab
% 入射方向 (BS → 反射点)
v_in = (p_ref - p_bs) / norm(p_ref - p_bs);
theta_tx = acos(v_in(3));        % 俯仰角: 0~π
phi_tx   = atan2(v_in(2), v_in(1)); % 方位角: -π~π

% 波束扫描: 在方位角方向等间隔扫描
phi_tx_beams   = phi_tx + deg2rad(linspace(-10, 10, N_beams));
theta_tx_beams = theta_tx * ones(1, N_beams);
```

### 7.2 接收端（UAV）

```matlab
% 出射方向 (反射点 → UAV), 即 AoA 来波方向
v_out = (p_ue - p_ref) / norm(p_ue - p_ref);
theta_rx = acos(v_out(3));        % 俯仰角: 0~π (UAV在反射面上方, θ<90°)
phi_rx   = atan2(v_out(2), v_out(1)); % 方位角: -π~π
```

### 7.3 反射参数估计中的使用

```matlab
% 从 AoA 估计值计算 v_out (无需取反!)
v_out(:,k) = [sin(theta_est(k)) * cos(phi_est(k));
              sin(theta_est(k)) * sin(phi_est(k));
              cos(theta_est(k))];

% 搜索变量 r 也是单位向量 (镜面反射方向)
r(phi, theta) = [sin(theta) * cos(phi);
                 sin(theta) * sin(phi);
                 cos(theta)];

% Phong 散射角余弦
cos_beta = r' * v_out(:,k);
```

## 8. 常见错误与注意事项

### 8.1 ❌ v_out 取反（已修复）

**错误**：`v_out = -[sinθ cosφ; sinθ sinφ; cosθ]`

**原因**：误以为 AoA 方向向量指向 UAV → 反射点（即从阵列看向源），但标准阵列信号处理中，导向矢量的方向向量指向波传播方向（从源指向阵列）。

**正确**：`v_out = [sinθ cosφ; sinθ sinφ; cosθ]`

### 8.2 ❌ φ 的 atan2 参数顺序

**正确**：`phi = atan2(y, x)`，**不是** `atan2(x, y)`

### 8.3 ❌ 极角与仰角混淆

本项目使用**极角 (polar angle)** $\theta \in [0, \pi]$，从 $+z$ 轴测量。这不同于雷达/通信中常用的**仰角 (elevation)** $\in [-90°, 90°]$（从水平面测量，向上为正）。

两者关系：$\text{仰角} = 90° - \theta$。

**常见混淆**：$\theta = 135°$（极角）= 仰角 $-45°$（水平面向下 45°），不是「135° 的俯角」。

### 8.4 ❌ LCS 与 GCS 混用

当前仿真中 LCS = GCS（无姿态旋转）。后续引入 UAV 姿态后，所有 AoA 估计 $(\hat{\varphi}, \hat{\theta})$ 需通过 $\mathbf{R}_{bg}$ 旋转到 GCS 才能进行多 UAV 联合处理。

### 8.5 ❌ steering vector 缺少负号

导向矢量必须使用 $\exp(-j \cdot \text{phase})$，负号不可省略。这对应于波前到达阵元时的相位延迟。
