## 1. 问题定位：从信号特征到空间结构

### 1.1 动机

第一阶段已从原始 OFDM 接收信号中盲提取出两类独立的几何特征：

| 来源 | 输出 | 空间约束类型 |
|------|------|------------|
| SA2N / Grid2N (1a) | $\hat{\bm{\Omega}}_{n,k} \to \mathbf{v}_{n,k,\text{out}}$ | 方向射线：反射点 → 每架 UAV |
| VARPRO (1c) | $\hat{\mathbf{r}}_{n,\text{spec}}$ | 镜面反射方向：反射面出射 |

本阶段的任务是**将这些空间射线转化为三维几何实体**：

1. 同一波束的 $K$ 条 AoA 射线交汇 → 反射点坐标 $\mathbf{rsp}_n$
2. $N$ 个反射点拟合平面 → 法向量 $\mathbf{n}$
3. 镜面方向 + 法向量 → 逆推入射方向 → 交汇得基站位置 $\mathbf{p}_b$

全程仅需线性代数运算——矩阵乘法、伪逆、SVD——无需任何非线性迭代。

### 1.2 在盲重建链条中的位置

```
第一阶段 [信号 → 角度 + 时延 + 能量]
  ├── 1a. AoA        ← SA2N / Grid2N
  ├── 1b. TDOA       ← 互功率谱 WLS
  └── 1c. 反射参数   ← VARPRO + 消零投影

第二阶段 [几何特征 → 空间结构]  ← 本文档
  ├── 2a. 反射点交汇 ← 正交投影伪逆
  ├── 2b. 法向量     ← SVD / PCA
  └── 2c. BS 定位    ← 逆斯涅尔 + 正交投影伪逆
       输入: v_{n,k,out} + r_{n,spec} + p_k
       输出: rsp_n + n + p_b

第三阶段 [因子图全局平差 → 数字孪生]
  以第二阶段闭式解为初值 → LM 联合优化 → CRLB 精度
```

### 1.3 核心洞察

本阶段三个子问题的数学本质完全相同——**多射线交汇**。对每条射线构造一个正交投影矩阵，将"点到射线的垂直距离"表达为二次型 $\| \mathbf{H}(\mathbf{x} - \mathbf{p}) \|^2$，对所有射线求和后得到无约束二次型，伪逆直接给出闭式解。一个统一的代数结构贯穿三步，只是射线的起点和方向各不相同。

## 2. 几何预备：向量关系回顾

以下符号沿用 [3D_AoA_Estimation_Algorithm.md](3D_AoA_Estimation_Algorithm.md) §3.1 定义。设第 $n$ 个波束（$n = 1,\dots,N$）和第 $k$ 架 UAV（$k = 1,\dots,K$）。

**入射路径**（BS → 反射点）：

$$
\boxed{\mathbf{v}_{n,\text{in}} = \mathbf{rsp}_n - \mathbf{p}_b}
$$

$\mathbf{v}_{n,\text{in}}$ **不是单位向量**——其模长 $\|\mathbf{v}_{n,\text{in}}\|$ 即为 BS 到反射点的飞行距离 $d_{\text{in},n}$。

**出射路径**（反射点 → UAV）：

$$
\boxed{\mathbf{v}_{n,k,\text{out}} = \mathbf{p}_k - \mathbf{rsp}_n}
$$

AoA 估计给出的方向即为 $\mathbf{v}_{n,k,\text{out}}$ 的单位化。在交汇算法中我们仅需其**单位方向**，下文直接将 $\mathbf{v}_{n,k,\text{out}}$ 视为单位向量。

**镜面反射方向**（斯涅尔定律）：

$$
\boxed{\mathbf{r}_{n,\text{spec}} = \frac{\mathbf{v}_{n,\text{in}}}{\|\mathbf{v}_{n,\text{in}}\|} - 2\left(\frac{\mathbf{v}_{n,\text{in}}^T}{\|\mathbf{v}_{n,\text{in}}\|} \mathbf{n}\right) \mathbf{n}}
$$

$\mathbf{r}_{n,\text{spec}}$ 是**单位向量**（$\|\mathbf{r}_{n,\text{spec}}\| = 1$），仅依赖入射方向的单位向量和法向量，与飞行距离无关。该量由第一阶段 1c 的 VARPRO 算法在 $\mathbb{S}^2$ 上搜索得到。

## 3. 第一步：基于正交投影的反射点云交汇

### 3.1 几何直觉：异面直线的最近点

对于基站发射的第 $n$ 个波束，空间中所有 $K$ 架无人机（坐标为 $\mathbf{p}_k \in \mathbb{R}^{3 \times 1}$）都能通过第一阶段的 AoA 估计算法，提取出一个指向反射点 $\mathbf{rsp}_n \in \mathbb{R}^{3 \times 1}$ 的单位方向向量 $\mathbf{v}_{n,k,\text{out}}$。

> **注意**：这里的方向定义为"反射点 → UAV"（波传播方向）。由于后续正交投影矩阵仅依赖 $\mathbf{v}\mathbf{v}^T$，其符号不影响结果——这正是本算法与 AoA 方向约定天然兼容的原因。

理想情况下，这 $K$ 条射线应该完美交汇于一点。但在实际中，由于 AoA 存在估计噪声，这些射线在 3D 空间中互不相交——它们变成了**异面直线**。这就构成了一个经典的**多直线最近点求解问题**（multi-ray triangulation）。

### 3.2 正交投影矩阵的构造

为了不引入未知的"飞行距离"参数，我们为第 $k$ 架 UAV 观测到的第 $n$ 条射线构造一个极其优雅的正交投影算子（Orthogonal Projection Operator）：

$$
\boxed{\mathbf{H}_{n,k} = \mathbf{I}_{3} - \mathbf{v}_{n,k,\text{out}} \, \mathbf{v}_{n,k,\text{out}}^T \quad \in \mathbb{R}^{3 \times 3}}
$$

**数学属性**：
- **对称性**：$\mathbf{H}^T = \mathbf{H}$
- **幂等性**：$\mathbf{H}^2 = \mathbf{H}$（投影两次等于投影一次）
- **半正定性**：对任意 $\mathbf{x} \in \mathbb{R}^3$，$\mathbf{x}^T \mathbf{H} \mathbf{x} = \|\mathbf{x}\|^2 - (\mathbf{v}^T\mathbf{x})^2 \ge 0$（由 Cauchy-Schwarz 不等式保证）
- **秩**：$\text{rank}(\mathbf{H}) = 2$，零空间为 $\text{span}\{\mathbf{v}\}$

**物理意义**：空间中任意一个向量乘以 $\mathbf{H}$，都会被投影到与该射线垂直的平面上——$\mathbf{H}$ 将向量中平行于射线方向的分量精确地"扣掉"。

> :warning: **符号健壮性**：由于 $\mathbf{v}\mathbf{v}^T = (-\mathbf{v})(-\mathbf{v})^T$，无论我们使用"反射点 → UAV"还是"UAV → 反射点"的方向，投影矩阵完全相同。算法与任何 AoA 方向符号约定天然兼容。

### 3.3 最小二乘闭式求解与可逆性条件

对于空间中任意一点 $\mathbf{x}$，它到射线 $k$ 的垂直欧氏距离的平方可以简洁地表达为：

$$
\text{dist}^2(\mathbf{x}, \text{ray}_k) = \|\mathbf{H}_{n,k} (\mathbf{x} - \mathbf{p}_k)\|^2
$$

我们要找的漫反射点 $\mathbf{rsp}_n$，就是使得它到**所有 $K$ 条射线的垂直距离平方和最小**的那个点。构造目标函数：

$$
J(\mathbf{rsp}_n) = \sum_{k=1}^K (\mathbf{rsp}_n - \mathbf{p}_k)^T \mathbf{H}_{n,k}^T \mathbf{H}_{n,k} (\mathbf{rsp}_n - \mathbf{p}_k)
$$

利用 $\mathbf{H}_{n,k}$ 的对称幂等性（$\mathbf{H}^T \mathbf{H} = \mathbf{H}^2 = \mathbf{H}$），代价函数简化为：

$$
J(\mathbf{rsp}_n) = \sum_{k=1}^K (\mathbf{rsp}_n - \mathbf{p}_k)^T \mathbf{H}_{n,k} (\mathbf{rsp}_n - \mathbf{p}_k)
$$

这是一个关于 $\mathbf{rsp}_n$ 的二次型。对 $\mathbf{rsp}_n$ 求梯度并令其为 $\mathbf{0}$：

$$
\frac{\partial J}{\partial \mathbf{rsp}_n} = 2 \sum_{k=1}^K \mathbf{H}_{n,k} (\mathbf{rsp}_n - \mathbf{p}_k) = \mathbf{0}
$$

移项后，得到 $\mathbf{rsp}_n$ 的严密闭式解：

$$
\boxed{\hat{\mathbf{rsp}}_n = \left( \sum_{k=1}^K \mathbf{H}_{n,k} \right)^{-1} \left( \sum_{k=1}^K \mathbf{H}_{n,k} \mathbf{p}_k \right)}
$$

记 $\mathbf{A}_n = \sum_k \mathbf{H}_{n,k} \in \mathbb{R}^{3 \times 3}$，$\mathbf{b}_n = \sum_k \mathbf{H}_{n,k} \mathbf{p}_k \in \mathbb{R}^{3 \times 1}$，则为 $\hat{\mathbf{rsp}}_n = \mathbf{A}_n^{-1} \mathbf{b}_n$。

**可逆性条件**：只要 UAV 数量 $K \ge 2$ 且它们不在同一条直线上，求和矩阵 $\mathbf{A}_n$ 就是满秩可逆的。直观理解：每个 $\mathbf{H}_{n,k}$ 的零空间是其射线方向 $\mathbf{v}_{n,k,\text{out}}$，$K$ 个这种矩阵求和后，零空间是这 $K$ 个方向的**公共**零空间。若 UAV 不全部共线，它们没有公共零空间，$\mathbf{A}_n$ 满秩。

**退化情形速查**：

| 配置 | $\mathbf{A}_n$ 秩 | 结果 |
|------|-------------------|------|
| $K=1$ | 2 | 无穷多解（射线上任意点）→ 退化 |
| $K=2$，射线平行 | 2 | 仅能确定一个平面 → 退化 |
| $K=2$，射线不平行 | 3（满秩） | 可解，但无冗余 → 不推荐 |
| $K \ge 3$，方向不全共线 | 3（满秩） | **最小二乘解**，噪声被平均抑制 → 推荐 |

> **工程注意点**：循环 $N$ 次，我们就得到了墙面上的点云集合 $\{\hat{\mathbf{rsp}}_1, \dots, \hat{\mathbf{rsp}}_N\}$。在实际部署中建议 $K \ge 3$，既保证可逆性又通过冗余观测压制 AoA 噪声。

## 4. 第二步：基于 SVD 的反射面法向量反演

### 4.1 几何直觉：在点云中寻找"最扁平"的方向

我们现在得到了 $N$ 个漫反射点，物理上它们必须共面——它们落在同一堵墙面上。现在我们要拟合这个平面并提取其单位法向量 $\mathbf{n}$。由于第一步得到的点云带有些许各向异性的高斯噪声，使用总体最小二乘（Total Least Squares）或 PCA 是最稳健的选择。

本节将从一个极其形象的几何类比出发，逐步推导至严密的代数证明。

**撒一把黄豆在桌面上**——这是理解整个 PCA/SVD 法向量提取的最佳比喻。

想象三维空间中的一把黄豆散乱地铺在桌面上（这就像我们算出来的漫反射点 $\hat{\mathbf{rsp}}_n$）。观察这个"黄豆堆"：

```
         桌面（反射面）
    ┌─────────────────────
    │  ●  ●   ●     ●     ← 黄豆 = 反射点 rsp_n
    │    ●   ●  ●    ●
    │  ●    ●     ●  ●
    │  ●  ●   ●      ●
    └─────────────────────
         ↑ 法向量 n：黄豆散布最小的方向
```

- 黄豆在**桌面的长度方向**散得最开 → **最大方差** → **第一主成分**
- 黄豆在**桌面的宽度方向**散得次开 → **次大方差** → **第二主成分**
- 黄豆在**垂直于桌面的方向**上呢？散布几乎为零（桌面平整的话，厚度就是 0）→ **最小方差** → **第三主成分** = **法向量！**

在数学中，**方差（Variance）**就是衡量数据在某个方向上"散布程度"的物理量。协方差矩阵 $\mathbf{C}$ 的本质，就是用一个 $3 \times 3$ 矩阵同时捕捉点云在所有方向上的散布。对该矩阵做特征分解，相当于问：

> "沿哪个方向看，数据的方差最大？沿哪个方向看，方差最小？"

由于这些点本该共面，那个"散布最小、厚度最薄"的方向，必然就是**垂直于该平面的法向量**。这就是为什么我们一定要找**最小特征值（奇异值）**对应的特征向量的几何根源。

### 4.2 从几何直觉到最优化问题

把上述直觉写成严格的数学公式。假设平面的中心点为 $\mathbf{c}$（点云质心），法向量为 $\mathbf{n}$（未知，要求解，且 $\|\mathbf{n}\| = 1$）。空间中任意一个反射点 $\hat{\mathbf{rsp}}_n$ 到这个平面的垂直距离 $d_n$ 可以通过向量点乘投影计算：

$$
d_n = \left| \mathbf{n}^T (\hat{\mathbf{rsp}}_n - \mathbf{c}) \right|
$$

将去中心化后的点记为 $\tilde{\mathbf{p}}_n = \hat{\mathbf{rsp}}_n - \mathbf{c}$，距离简化为 $d_n = |\mathbf{n}^T \tilde{\mathbf{p}}_n|$。

**计算质心**：

$$
\mathbf{c} = \frac{1}{N} \sum_{n=1}^N \hat{\mathbf{rsp}}_n
$$

**构造 $3 \times 3$ 协方差矩阵**（去中心化）：

$$
\boxed{\mathbf{C} = \sum_{n=1}^N \tilde{\mathbf{p}}_n \tilde{\mathbf{p}}_n^T \quad \in \mathbb{R}^{3 \times 3}}
$$

**构造目标函数**。理想情况下所有点都在平面上（$d_n = 0$），但有噪声。我们寻找一个法向量 $\mathbf{n}$，使所有点到该平面的**垂直距离平方和最小**：

$$
J(\mathbf{n}) = \sum_{n=1}^N (\mathbf{n}^T \tilde{\mathbf{p}}_n)^2
$$

利用矩阵转置性质 $(\mathbf{n}^T \tilde{\mathbf{p}}_n)^2 = (\mathbf{n}^T \tilde{\mathbf{p}}_n)(\tilde{\mathbf{p}}_n^T \mathbf{n})$，把求和符号放进中间：

$$
J(\mathbf{n}) = \mathbf{n}^T \left( \sum_{n=1}^N \tilde{\mathbf{p}}_n \tilde{\mathbf{p}}_n^T \right) \mathbf{n}
$$

仔细看括号里的部分——这正是我们前面构造的 $3 \times 3$ **协方差矩阵 $\mathbf{C}$**！目标函数变得极其简洁：

$$
\boxed{J(\mathbf{n}) = \mathbf{n}^T \mathbf{C} \, \mathbf{n}}
$$

### 4.3 拉格朗日乘子法严密推导

现在我们的数学问题变成了一个**约束最小二乘问题**：

> 在单位向量约束 $\mathbf{n}^T \mathbf{n} = 1$ 下，求 $\mathbf{n}$ 使得 $\mathbf{n}^T \mathbf{C} \mathbf{n}$ 最小。

构造拉格朗日函数：

$$
L(\mathbf{n}, \lambda) = \mathbf{n}^T \mathbf{C} \mathbf{n} - \lambda (\mathbf{n}^T \mathbf{n} - 1)
$$

对 $\mathbf{n}$ 求偏导数并令其为 $\mathbf{0}$（利用实对称矩阵的导数公式 $\frac{\partial (\mathbf{n}^T\mathbf{C}\mathbf{n})}{\partial \mathbf{n}} = 2\mathbf{C}\mathbf{n}$）：

$$
\frac{\partial L}{\partial \mathbf{n}} = 2\mathbf{C}\mathbf{n} - 2\lambda \mathbf{n} = \mathbf{0}
$$

化简后得到一个**惊人的等式**：

$$
\boxed{\mathbf{C}\mathbf{n} = \lambda \mathbf{n}}
$$

这是什么？这正是线性代数中最经典的**特征值与特征向量的定义式**！这意味着，我们要找的最佳法向量 $\mathbf{n}$，**必定是协方差矩阵 $\mathbf{C}$ 的某一个特征向量**——约束优化的解天然地落在特征向量上，这不是人为选择，而是数学结构的必然。

**那么该选哪个特征向量？**既然 $\mathbf{n}$ 是特征向量，把 $\mathbf{C}\mathbf{n} = \lambda\mathbf{n}$ 代回目标函数：

$$
J(\mathbf{n}) = \mathbf{n}^T (\mathbf{C}\mathbf{n}) = \mathbf{n}^T (\lambda \mathbf{n}) = \lambda (\mathbf{n}^T \mathbf{n}) = \lambda
$$

**结论呼之欲出**：

> **点云到拟合平面的误差平方和 $J(\mathbf{n})$，在数值上严格等于所选用特征向量的特征值 $\lambda$。**

我们要找的是使误差**最小**的法向量，自然就必须选择**最小的特征值** $\lambda_{\min}$ 所对应的特征向量！

这就是为什么 PCA/SVD 中的"最小奇异值方向"恰好就是平面法向量——不是经验规律，不是近似方法，而是**数学上的必然**。选任何其他特征向量，点到平面的距离平方和都会更大——因为 $J(\mathbf{n}) = \lambda$，而 $\lambda_{\min} \le \lambda_{\text{mid}} \le \lambda_{\max}$。

**SVD 求解**。对 $\mathbf{C}$ 进行奇异值分解（对实对称半正定矩阵，SVD 完全等价于特征值分解 EVD）：

$$
\mathbf{C} = \mathbf{U} \boldsymbol{\Sigma} \mathbf{U}^T, \quad
\boldsymbol{\Sigma} = \text{diag}(\sigma_1, \sigma_2, \sigma_3), \quad
\sigma_1 \ge \sigma_2 \ge \sigma_3 \ge 0
$$

> **补充说明**：对协方差矩阵这类实对称半正定矩阵，SVD 的奇异值 $\sigma_i$ 与 EVD 的特征值 $\lambda_i$ 满足 $\sigma_i = \lambda_i$（因为 $\mathbf{C} \succeq 0$ 保证所有特征值非负）。"最小奇异值对应的右奇异向量"和"最小特征值对应的特征向量"是完全同一件事。

最小的奇异值 $\sigma_3$ 对应平面在法向上的数据方差（理论上无噪声时应为 $0$）。因此，矩阵 $\mathbf{U}$ 的第三列——即对应 $\sigma_3$ 的奇异向量——就是我们要找的墙面单位法向量，记为 $\mathbf{n}_{\text{raw}}$。

### 4.4 方向消歧

SVD 算出的特征向量的符号是不确定的：$\mathbf{n}_{\text{raw}}$ 和 $-\mathbf{n}_{\text{raw}}$ 都是数学上的合法解。这两个方向在代数上完全等价（对应同一个特征值），但在物理上只能有一个正确。

**物理约束**：墙面法向量必须指向无人机所在的一侧——否则信号不可能从墙面反射到达无人机（违反菲涅尔反射的物理因果性）。取任意一架无人机位置 $\mathbf{p}_1$，通过内积判断方向：

$$
\boxed{\mathbf{n} = \begin{cases}
\mathbf{n}_{\text{raw}},  & \text{if } \mathbf{n}_{\text{raw}}^T (\mathbf{p}_1 - \mathbf{c}) > 0 \quad (\mathbf{n}_{\text{raw}} \text{ 已指向 UAV 侧}) \\[4pt]
-\mathbf{n}_{\text{raw}}, & \text{if } \mathbf{n}_{\text{raw}}^T (\mathbf{p}_1 - \mathbf{c}) < 0 \quad (\mathbf{n}_{\text{raw}} \text{ 指向墙背面, 需翻转})
\end{cases}}
$$

> **极易踩坑的细节**：如果 $|\mathbf{n}_{\text{raw}}^T (\mathbf{p}_1 - \mathbf{c})|$ 非常接近 $0$，说明 $\mathbf{p}_1$ 几乎在墙平面上——此时换一架空间位置更远的 UAV 来判断。实际中飞机不会贴着墙面飞，此情形极为罕见。

## 5. 第三步：逆斯涅尔定律与基站代数定位

### 5.1 反射矩阵的自反性

在第一阶段中，我们通过 VARPRO 从能量包络中提取出了第 $n$ 个波束离开墙面的理想镜面反射单位向量 $\mathbf{r}_{n,\text{spec}}$。现在法向量 $\mathbf{n}$ 已由 SVD 精确求出，我们完全有能力利用斯涅尔定律"时光倒流"——反推出入射光是从哪里打过来的。

设 $\mathbf{u}_n \triangleq \mathbf{v}_{n,\text{in}} / \|\mathbf{v}_{n,\text{in}}\|$ 为从 BS 指向反射点的单位入射向量。AoA 文档 §3.1 式 (6) 的镜面反射公式：

$$
\mathbf{r}_{n,\text{spec}} = \mathbf{u}_n - 2(\mathbf{u}_n^T \mathbf{n})\mathbf{n}
$$

定义镜面反射矩阵（Householder 反射）：

$$
\boxed{\mathbf{R} = \mathbf{I} - 2\mathbf{n}\mathbf{n}^T \quad \in \mathbb{R}^{3 \times 3}}
$$

则上式简写为 $\mathbf{r}_{n,\text{spec}} = \mathbf{R} \mathbf{u}_n$。

$\mathbf{R}$ 具有一个极其优美的代数性质——**自反性**（involution）：

$$
\mathbf{R}^2 = (\mathbf{I} - 2\mathbf{n}\mathbf{n}^T)(\mathbf{I} - 2\mathbf{n}\mathbf{n}^T) = \mathbf{I} - 4\mathbf{n}\mathbf{n}^T + 4\mathbf{n}(\mathbf{n}^T\mathbf{n})\mathbf{n}^T = \mathbf{I}
$$

即 $\mathbf{R}^{-1} = \mathbf{R}$。几何直观：镜面反射做两次回到原位——对着镜子看自己，镜中的你也在看着你。

利用自反性，我们直接把反射公式"反过来用"，瞬间得到 BS 指向墙面的绝对入射方向：

$$
\boxed{\mathbf{u}_n = \mathbf{r}_{n,\text{spec}} - 2(\mathbf{r}_{n,\text{spec}}^T \mathbf{n}) \mathbf{n}}
$$

> 仅需一次向量运算即可**无损地**恢复入射方向——不需要迭代，不需要优化，不引入任何近似误差。这就是自反性赋予的"时光倒流"能力。

### 5.2 基站的镜像正交投影交汇

此时问题奇妙地转化为了与**第一步完全镜像**的问题：

我们有 $N$ 个起点（漫反射点 $\hat{\mathbf{rsp}}_n$），每个起点发射出一条反向射线（方向为 $-\mathbf{u}_n$，指向基站）。这 $N$ 条反向射线在理想状态下必须交汇于同一个点——基站 $\mathbf{p}_b$！

重复与第一步完全相同的套路——构造射线投影矩阵：

$$
\mathbf{H}_{b,n} = \mathbf{I}_{3} - \mathbf{u}_n \mathbf{u}_n^T
$$

令所有反向射线的投影距离平方和最小，立刻得到基站坐标的严密闭式解：

$$
\boxed{\hat{\mathbf{p}}_b = \left( \sum_{n=1}^N \mathbf{H}_{b,n} \right)^{-1} \left( \sum_{n=1}^N \mathbf{H}_{b,n} \hat{\mathbf{rsp}}_n \right)}
$$

**可逆性条件**：$N \ge 2$ 且 $N$ 个波束的入射方向 $\mathbf{u}_1, \dots, \mathbf{u}_N$ 不全部共线。物理含义：若所有波束从完全相同方向入射（平行入射），则 BS 沿该方向存在距离模糊。实际扫描波束保证了方向多样性，此条件自然满足。

**误差放大的双重依赖**：BS 定位精度同时受第一步 $\hat{\mathbf{rsp}}_n$ 的估计误差和第二步 $\mathbf{n}$ 的估计误差双重影响。当 $\mathbf{n}$ 有偏差时，$\mathbf{u}_n$（通过逆斯涅尔恢复的入射方向）也偏差，最终体现为 $\hat{\mathbf{p}}_b$ 的定位误差。两层误差均通过 $3 \times 3$ 矩阵求逆线性传播，可通过条件数定量评估。

## 6. 端到端处理流程与接口契约

### 算法伪代码

```
Algorithm: Phase 2 — Linear Geometric Inversion
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Input:  v_{n,k,out}  ← Phase 1a (SA2N / Grid2N AoA)
        r_{n,spec}   ← Phase 1c (VARPRO)
        p_k          ← UAV positions (known)

Step 1 — Reflection Point Triangulation:
  For n = 1 .. N:
    A_n = 0_{3×3},  b_n = 0_{3×1}
    For k = 1 .. K:
      H_{n,k} = I₃ - v_{n,k,out} v_{n,k,out}^T
      A_n += H_{n,k}
      b_n += H_{n,k} p_k
    rsp_n = A_n^{-1} b_n                ← 3×3 linear solve

Step 2 — Wall Normal via SVD:
  c      = (1/N) Σ_n rsp_n
  C      = Σ_n (rsp_n - c)(rsp_n - c)^T
  [U,Σ]  = svd(C)                       ← 3×3 SVD
  n_raw  = U(:, 3)                      ← min singular vector
  n      = sign(n_raw^T(p₁ - c)) · n_raw

Step 3 — BS Localization via Inverse Snell:
  A_b = 0_{3×3},  b_b = 0_{3×1}
  For n = 1 .. N:
    u_n   = r_{n,spec} - 2(r_{n,spec}^T n) n
    H_{b,n} = I₃ - u_n u_n^T
    A_b += H_{b,n}
    b_b += H_{b,n} rsp_n
  p_b = A_b^{-1} b_b                   ← 3×3 linear solve

Output:  {rsp_n}_{n=1..N},  n,  p_b
```

### 输入输出契约

| 方向 | 内容 | 维度 | 来源 / 去向 |
|------|------|------|-----------|
| **输入** | AoA 出射方向 $\hat{\mathbf{v}}_{n,k,\text{out}}$ | $3 \times 1$，$NK$ 个 | SA2N / Grid2N (1a) |
| **输入** | 镜面反射方向 $\hat{\mathbf{r}}_{n,\text{spec}}$ | $3 \times 1$，$N$ 个 | VARPRO (1c) |
| **输入** | UAV 绝对位置 $\mathbf{p}_k$ | $3 \times 1$，$K$ 个 | GPS / 先验标定 |
| **输出** | 反射点坐标 $\hat{\mathbf{rsp}}_n$ | $3 \times 1$，$N$ 个 | → 第三阶段状态向量 |
| **输出** | 反射面法向量 $\hat{\mathbf{n}}$ | $3 \times 1$ | → 第三阶段状态向量 |
| **输出** | BS 位置 $\hat{\mathbf{p}}_b$ | $3 \times 1$ | → 第三阶段状态向量 |

> **总结**：至此，没有任何迭代，没有提供任何初始猜测，我们仅依靠纯粹的线性代数和几何光学，就完美解出了 $\hat{\mathbf{rsp}}_n$、$\mathbf{n}$ 和 $\hat{\mathbf{p}}_b$。三个子问题共享同一个优雅的代数结构（正交投影 → 伪逆），三步之间首尾相接形成完整的几何反演链。

## 7. 数值考虑与实现要点

### 7.1 矩阵求逆的数值稳定性

第一、三步均需求解 $3 \times 3$ 线性方程组。推荐使用 MATLAB 的 `A \ b`（反斜杠）运算符。若 $\text{cond}(\mathbf{A}_n) > 10^6$（近似奇异），使用 Tikhonov 正则化：$\mathbf{A}_n \leftarrow \mathbf{A}_n + 10^{-8}\mathbf{I}_3$。

### 7.2 SVD 数值实现

$3 \times 3$ 协方差矩阵的 SVD 等价于实对称矩阵的 EVD。实践中 `svd` 比 `eig` 更数值稳定。若点云数量 $N < 3$，协方差矩阵不满秩 → 法向量不可信。$N = 3$ 时三个点仍可定唯一平面（$\mathbf{C}$ 秩为 2），$N \ge 5$ 推荐以提供冗余。

### 7.3 与第三阶段的衔接

本阶段的代数闭式解作为第三阶段因子图 LM 联合优化的初始猜测点。三个关键优势：

1. **无需初始猜测** → LM 不会陷入局部极值
2. **闭式解已逼近全局最优** → 通常 3–5 次 LM 迭代即可收敛至 CRLB 精度
3. **离群值检测**：若某波束的 AoA 严重偏差，其 $\hat{\mathbf{rsp}}_n$ 到拟合平面的残差会显著增大 → 可作为第一阶段 1a 的质量反馈信号

### 7.4 误差传播预评估

以当前仿真参数（AoA SNR = 10 dB，$K = 6$，$N = 5$）粗略估计：

- **反射点精度**：$K$ 次伪逆平均，角度误差被条件数压缩，预计 $0.1$–$0.5$ m（依赖 UAV 几何散布）
- **法向量精度**：$N$ 点 SVD 拟合，对异常值天然稳健，预计 $1°$–$3°$ 误差
- **BS 定位精度**：双重误差传播（$\mathbf{n}$ 误差 → $\mathbf{u}_n$ 误差 + $\mathbf{rsp}_n$ 误差 → $\mathbf{p}_b$ 误差），预计须通过一阶扰动理论精确建模

> 精确的误差传播协方差（从 AoA 估计协方差到最终 $\mathbf{p}_b$ 协方差）留待第三阶段联合优化时统一推导。
